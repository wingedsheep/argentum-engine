# Token art gaps

Tokens our cards create that have no set-scoped art, so they render with the
engine-wide generic art for their creature type. Generated by
`just token-art-gaps` — do not hand-edit.

**None.** Every token our cards can create resolves to art from the set that
printed the creating card.

This regresses the moment a card is added whose set prints a token Scryfall has no
`t<code>` row for — re-run to get the work queue back, with a suggested
`web-client/public/images/tokens/<file>.jpeg` path and a paste-ready
`TokenPrinting(...)` row for each gap.
